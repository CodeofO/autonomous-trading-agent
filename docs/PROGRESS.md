## 남은 일 / 사람이 해야 할 일

1. **토스 키**: WTS → 설정 > Open API 에서 발급해 `.env` 의 `TOSS_CLIENT_ID`/`TOSS_CLIENT_SECRET` 에 넣고, 같은 화면에서 **허용 IP** 를 등록하세요. 실키로는 아직 호출해 보지 않았습니다.
2. **재무제표·뉴스 키**(선택): OpenDART 인증키, 네이버 검색 API. 없으면 매니저가 재무·뉴스 없이 시세만으로 판단합니다.
3. 실키 확보 후 실제 응답으로 픽스처를 다시 녹화하세요(현재 픽스처는 공식 문서 스키마 기반, `backend/tests/fixtures/README.md`).

## 알려진 문제 · 제약

| 항목 | 내용 | 대응 |
|---|---|---|
| 시세 지연 | (공공데이터 모드만) T+1 일봉 → 체결 확정이 다음 날 | 토스 모드에서 해소(D-24) |
| 실시간 체결 낙관성 | 토스 모드는 거래량·호가 잔량을 보지 않고 현재가로 전량 체결 | 큰 주문은 실제보다 유리할 수 있음(D-24) |
| LLM 토큰 사용량 | 실제 세션 1회 약 17만 토큰(도구 결과가 대화에 누적) | `LLM_MAX_STEPS` 축소 또는 정책에 '보유 종목 위주' 명시로 절감 |
| 실키 미검증 | 공공데이터 숫자 필드 타입, `items.item` 단건 형태, `endBasDt` 경계, DART 계정명 편차 | 관대한 파싱으로 처리했지만 실응답 확인 필요(`TODO(verify)`) |
| 휴장일 | 내장 목록은 best-effort | 실제와 다르면 `core/market_calendar.py` 수정 |
| 매도세율 | 0.20% 가정 | `.env` `PAPER_SELL_TAX_RATE` 로 조정 |
| LLM 비용 | 세션당 최대 24단계 tool 호출 | `LLM_MAX_STEPS` 로 상한 조정 |
| 규칙 에이전트 | 단순 점수 합산 예시 — 성과 기대 금지 | LLM 연결 권장 |
| 인증 | 기본 로그인 없음(127.0.0.1 전용). `AUTH_ENABLED=true` 시 로컬 단일 사용자, HTTP | 외부 공개 배포 금지(범위 밖) |
| 컨테이너 로그 시각 | slim 이미지에 tzdata 가 없어 로그 시각이 UTC 로 보일 수 있음 | 기능 영향 없음 |
| eslint 경고 4건 | react-refresh 의 개발용 핫리로드 안내 | 기능 영향 없음 |
